## How to sign

Do not edit this file. On your first pull request, a bot will ask you to sign by posting a comment on
that pull request with exactly this sentence:

```
I have read the CLA Document and I hereby sign the CLA
```

Your signature (your GitHub username, the pull request number and the date) is recorded in
`signatures/version1/cla.json` in this repository. One signature covers all of your future
contributions, unless this agreement changes version.

If you are contributing on behalf of a company, have someone who can bind the company sign it, and
say so on the pull request.
