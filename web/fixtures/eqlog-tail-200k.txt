# These are bytes a real EverQuest Legends client wrote. They were not authored
# alongside the test that reads them. The source is the log file
#   eqlog_Reviir_freeport.txt   61,493,318 bytes, last written 2026-07-22
# in the game's own Logs directory on the machine this fixture was cut on.
#
# CUT. A contiguous 204797-byte run of 2385 whole lines, taken at byte
# offset 12,387,671 of that file and snapped forward to the first line boundary.
# It is cut from mid-file rather than from the very end on purpose. All four logs
# on this machine -- 310,354,550 bytes between them -- carry exactly twelve bytes
# above 0x7F in total, and none of them are in any log's last 2 MB. A slice off
# the end would have been pure ASCII, and AC-003 says that in that case the slice
# is re-cut from the log until it carries a non-ASCII character and the offset is
# recorded. That is what happened and that is the offset.
#
# SCRUB. Other players' names were replaced before check-in. 65 names were
# collected from the log's own speech and combat line shapes, and each was
# replaced, everywhere it occurred, by a generated name of exactly the same byte
# length, so the byte count above is the byte count as cut. Reviir is the log
# owner's own character and is kept. The substitution over-reaches rather than
# under-reaches: a few of the 65 are game vocabulary rather than players, and
# renaming a monster is harmless here where missing a player would not be.
#
# WHAT IT IS FOR. Byte-level chunk invariance and character-boundary safety over
# bytes nobody chose. The four chunk sizes the test feeds these bytes through are
# the test's own invention -- no real reader asks for one byte at a time -- but
# the bytes are not.
#
